# LogBridge 界面计划

本文件记产品边界、信息架构和本机验证步骤。色彩数字仍以 `color/` 与现有测试为准。整段代理，代理精度。已实现（未验证）。

## 产品定位

LogBridge 是 macOS 上的本地调色与交付工具：混源 Log 素材选出成对 IDT，看预览，写出剪辑软件能打开的代理（默认 ProRes 422 HQ；高级可选 ACES2065-1 EXR），并可带达芬奇节点包。

它不是剪辑软件。不剪多轨，不提供模板或特效货架。

## 现有栈与主路径

- 界面：SwiftUI，单窗口，macOS 14+。工程在 `macos/LogBridge/LogBridge.xcodeproj`。
- 色彩真源：`color/`（Python）。App 里的预览和写出走同一套已有公式，本轮不改数字。
- 文案：`locale/ui_zh.json` 与 `UICopy.swift`。

主路径：打开 → 拖入或「添加…」→ 每条选成对 IDT → 预览里看曝光和白平衡 → 「处理已锁定片段」→ 写出说明 → 选文件夹。

未锁定的素材跳过，不猜 IDT。

## 仓内核实

- **没有剪辑时间线。** 预览下方只有帧滑条（有帧率元数据才出现）。仓库里的「时间线」字样出现在达芬奇包说明，指 ACEScct 工作空间，不是多轨时间线。本轮不加重轨。
- **示波器不进默认界面。** 友好版只在「高级」里放直方图，标明仅预览、不参与写出、不是示波器读数。波形和矢量以后再评估，仍默认收起。

## 信息架构

对照四家之后采用的做法：

- 单窗三区：素材列表 | 大预览（角标「仅预览」）| 右侧检查器（跟当前选中）。
- ⌘, 是全局偏好：默认预览、默认写出格式、外观、导入后是否提示估计白平衡。改完即生效，没有保存或取消。
- 本片：成对 IDT 记在当前素材上。曝光和白平衡改完即在预览里生效；写出时，已锁定素材共用检查器里当前这一套曝光和白平衡，每条仍用自己的成对 IDT。
- 写出是独立说明面板，确认后再走原来的选文件夹。不放进偏好设置。面板列出每条会写出的源文件名、成对 IDT，以及将得到的代理名（默认 `{名}_Rec709_proxy.mov`；高级 EXR 是 `{名}_ACES2065-1_proxy`），还有每条会跳过的文件名和原因。没有已锁定时，菜单「写出…」不起作用。
- 节点、EXR、直方图在「高级」，默认收起。

不采用的做法：多页工作区、自由拆窗、把节点图当成第一眼、用宣传口径把代理说成已经做完的画面。

## 本轮界面

- 顶栏：添加、设置、写出。标题下有一行当前步骤：先拖入或点添加；有素材未锁定时去右侧选成对 IDT；已锁定则可调色再写出；写出进行中是「正在写出代理」；写出完成后是「已写出代理。可再调色，或在状态栏打开 Finder」。
- 左侧拖放区在已有素材时仍可点，继续添加。空列表时检查器写「先拖入或点添加」，不叫人去点一条还不存在的素材。
- 拖入后左侧先写「正在读入…」。读入成功写「读入 N 条」，并指出下一步：还有待选就去右侧选成对 IDT；都已锁定就可以看预览再写出。文件夹里没有能读的素材时写「没有能读的素材」，不保持沉默。跳过仍是「未导入 N 条」，成功读入会换掉上一次的跳过说明。若当前筛选是「待选」或「已锁定」，而这一批里有被筛掉的条目，列表回到「全部」，新素材能点到。不猜 IDT，也不改这一套曝光和白平衡。
- 读入后，左侧每一行、监视器读数下、检查器标题下、写出说明里共用一行画面信息。读到宽高就写 `宽×高`。影片再写帧率（23.976 仍是 23.976 帧/秒，整数就写整数）和时长；缺的不写，不猜 24 或 30。静帧写「静帧」，不写帧率。这是片源尺寸，不是预览缩小后的画面。不参与写出，也不改这一套调色。
- 左侧素材列表加大拖放区和行高。点一行只选中并刷新预览。
- 左侧每一行，以及检查器标题旁，有一张小图。它是这条源（相机 Log）的第一帧，角上写「源」。静帧就是这一张。只在这一行出现时才取，长边缩小，只留在内存里，不写入磁盘。不是调色预览，不含曝光和白平衡，也不参与写出。拖滑条或播放时，小图仍是第一帧，不跟着当前预览帧走。解不出来就写「没有画面」，不猜成对 IDT。写出进行中不再新取。从列表拿掉这一条，小图也丢掉。
- 中间监视器尽量占高。默认左源右预览。可切到「预览」把调色画面放大；点灰卡时仍显示预览。空窗口写明拖入或点添加。
- 右侧检查器：成对 IDT，再是可折叠的曝光和白平衡（默认展开）。标题固定，下面整栏滚动。窗口变矮时仍能滚到曝光和白平衡。
- 成对 IDT 在检查器里是一列，点一行就锁定，并停在这条看预览。检测到只有两对时（S-Log3、C-Log2、C-Log3）直接列出那两行。整表超过 4 行时，上面有「查找 Log 或色域」，可输入索尼、Sony、LogC、佳能这类词缩小列表。查找只收这一列，不会因为只剩一对就替你选。没有匹配时写「没有匹配的成对 IDT」。当前这一对被查找筛掉时，仍写明清空后它还在。换一条素材，查找清空。写出进行中不能点。Venice 对仍只在检测到时出现。超过 6 行时这一列自己滚动，高度到此为止，下面仍能滚到曝光和白平衡。
- 曝光打开时，滑条旁有 −0.10、归零、+0.10。和监视器读数是同一套，预览跟着变。范围仍是 −8 到 +8 档。写出仍用当前这一套。写出进行中或设置、写出说明打开时，步进不起作用。
- 白平衡打开且已有色温时，滑条旁有 −100 K、回到机内、+100 K。每次 100 K，范围仍是 2000 到 10000。回到机内把**当前这条**的机内色温和绿品写入全片这一套；读不到机内就清空，不猜 5600 或 6504。色温空着时不能步进。写出进行中或设置、写出说明打开时，步进和回到机内不起作用。
- 白平衡打开且已有色温时，绿品滑条旁有 −1、绿品归零、+1。每次 1，范围仍是 −10 到 +10。绿品归零只把绿品收到 0，色温不动。回到机内才把当前这条的机内绿品写入这一套。色温空着时不能步进。写出进行中或设置、写出说明打开时，步进不起作用。
- 曝光和白平衡是全片这一套。点另一条、上下方向键换一条、或再拖入，都不会改掉旋钮，也不会改掉写出要用的那一套。监视器读数仍是这一套。检查器会写明这条自己的机内读数。第一条若读到机内色温，会用来填这一套；之后不再用别的素材覆盖。
- 这一套可以退回上一次。选中素材时，检查器标题下有「撤销这一套」和「重做这一套」，菜单「调色」是同一套。⌘Z 和 ⇧⌘Z 也是。一次拖动滑条算一步，松开鼠标后再拖是另一步。步进、归零、回到机内、开关、适应方法、点灰卡、确认估计，各算一步。撤销只动曝光和白平衡，不改成对 IDT，不改预览帧，不改这次预览，也不改列表里选中的是哪一条。播放会停。写出用撤销之后的这一套。写出进行中，或设置、写出说明、导入、正在打开选文件夹时，这两下是灰的。查找框里的 ⌘Z 仍改文字。第一条用机内读数填这一套，这一下不记进撤销。不猜 5600 或 6504。
- 素材列表可筛「全部 / 待选 / 已锁定」。筛选只收列表。当前这条若被筛掉，监视器仍留着它。上下方向键在筛出来的结果里移动。
- 有帧范围时，预览帧滑条旁有「播放」「回到开头」「上一帧」「下一帧」「到结尾」。播放按这条素材自己的帧率往前走，这一帧还没画完就等它，不再叠着要下一帧，到最后一帧就停，不绕回。空格和菜单「调色」里的「播放预览」是同一套。静帧、读不到帧率或时长时没有播放，也不猜帧率。拖滑条、点上一帧或下一帧、换一条、再拖入、点灰卡、打开设置或写出说明、开始写出，都会停。左右方向键和菜单「调色」仍是每次一帧，到头就停。读到帧率时，滑条旁还有「退 1 秒」和「进 1 秒」：按这条帧率四舍五入到整帧，一次大约 1 秒，到头就停在开头或结尾。读不到帧率就不出现这两下，不猜 24 或 30。⇧←、⇧→ 和菜单「调色」是同一套。播放中按这两下会停。写出进行中，或设置、写出说明、导入打开时，步进和播放都不起作用。不改曝光和白平衡，不参与写出。
- 有帧范围且读到帧率时，滑条下面这一行写出帧数，以及这一帧的预览时间，和最后一帧的预览时间，中间用斜线分开。两边都是第几帧（从 0 计）除以这条的帧率，显示到毫秒。右边不是片源时长，也不是时间码。读不到帧率就不写时间，不猜 24 或 30。滑条留在上面。点「回到开头」或按 Home 回到第 1 帧；已经在开头时这一下是灰的，播放中按 Home 会停。点「到结尾」或按 End 到最后一帧；已经在结尾时是灰的。菜单「调色」是同一套。这只改预览帧，不改曝光和白平衡，不参与写出。静帧没有这两下。
- 已锁定时，监视器可以「看调色前」。画面仍走这条的成对 IDT 和这次预览，但不含曝光和白平衡。检查器数字不动，写出说明仍是这一套。再点「回到调色」，或菜单「调色」里的同一项（⌥⌘\），回到含这一套的预览。当前帧不动。未锁定时不能打开。写出进行中，或设置、写出说明、导入、点灰卡时，不能切换。不猜色温。
- 有素材时，监视器读数旁可切「适应 / 100% / 200%」。适应是整幅塞进窗口。100% 是预览画面的一个像素对一个屏幕像素，不是片源逐像素，预览长边仍会缩小。200% 再大一倍，先停在中央，可拖动看旁边。分屏时源和预览一起放大、一起拖动。换放大倍数，或换一条，回到中央。不改这一套调色，不参与写出。点灰卡时画面回到适应，取样仍按整幅；点完回到刚才的放大，拖到的位置还在。
- 监视器标题下有一行读数：当前素材名、曝光档、白平衡。有色温时这一行带上绿品，和写出说明是同一套。和检查器同一套数字，仅预览，不参与写出。旁边有「这次预览」（Rec.709 / HLG / PQ），只改这次监视器。默认预览仍在 ⌘,。不改写出。
- 预览至少留一块高度。写出条收成少量行，把高度留给预览。主按钮先打开写出说明。说明面板收起后才打开系统选文件夹，避免两层叠在一起。收起后顶栏写「正在打开选文件夹」，写出条写明选文件夹会贴在这个窗口上。取消则不写出。选文件夹贴在主窗口上，不另飘一个容易被挡住的面板。这段时间不能再开设置或写出说明。写出进行中同一按钮变为「取消」。
- 「高级」展开后在自己的高度里滚动，不把监视器顶没。直方图下面有亮度波形，按当前预览从左到右铺开。仅预览，不参与写出，不是示波器读数。默认收起。
- 菜单「调色」：曝光 +0.10（⌥⌘=）、曝光 −0.10（⌥⌘-）、曝光归零（⌥⌘0）、色温 +100（⌥⌘]）、色温 −100（⌥⌘[）、回到机内（⌥⌘9）、绿品 +1（⌥⌘.）、绿品 −1（⌥⌘;）、绿品归零（⌥⌘'）、下一条待选（⌘]）、回到开头、退 1 秒、上一帧、下一帧、进 1 秒、到结尾、播放预览、看调色前（⌥⌘\）、撤销这一套、重做这一套。曝光、色温和绿品和检查器是同一套，不另记数字。撤销和重做只动这一套曝光和白平衡。回到开头、到结尾、退 1 秒、进 1 秒、上一帧、下一帧和播放只改预览帧。看调色前只改监视器画面。播放中再点菜单是「暂停预览」。
- 素材已进来但当前这条还没锁定时，监视器底部和写出条都会写下一步：到右侧检查器选成对 IDT。选完才出现「处理已锁定片段」。
- 选完成对 IDT 后仍停在这一条，预览按这一对重算。还有别的待选时，检查器有「下一条待选」，不替你选。
- 写出说明在收起之前一直是写出说明，不会中途换成设置。说明里写明当前这一套曝光和白平衡，这一套会套到已锁定素材。每条仍用自己的成对 IDT。
- 写出说明和选文件夹都写出占用估算，数字跟当前格式走。默认 ProRes 按每像素 1 字节估算，不拿 EXR 的未压缩浮点图（6 字节）来拦。高级 EXR 仍按 6 字节。空间不够仍是「磁盘空间不足，未写出」，不开始写。达芬奇包写不完整时，刚写出的 ProRes 也会删掉，状态是「达芬奇包不完整，未写出」。ProRes 按帧写入，不把整段画面先堆在内存里。
- 写出进行中，监视器下那一行是「写出代理 i/N · 这条文件名」。这条读到总帧数时再写「第 k / 共 m 帧」；静帧共 1 帧。读不到帧率或时长就不写总帧数，不猜 24 或 30。左侧这一行标「正在写出」，列表会滚到它。不改选中，也不改这一套调色。
- 写出完成后，这一行在「已写出代理」下写出刚得到的文件名。点「已写出代理」在 Finder 打开这个文件。默认是 `{名}_Rec709_proxy.mov`。高级 EXR 仍打开 `{名}_ACES2065-1_proxy`。失败、待选、已取消不打开。状态栏「在 Finder 中显示」仍是这一批。
- 全局偏好增加外观（跟随系统 / 深色 / 浅色），只改窗口明暗，不改预览色彩标签，也不改写出。

## 在 Mac 上试用

Linux 上不能编出 `.app`。下面交给本机 Xcode。

1. 安装 Xcode 15 或更新。
2. 打开 `macos/LogBridge/LogBridge.xcodeproj`。
3. Scheme 选 **LogBridge**，运行（▶）。或 Product → Archive → Distribute App → Copy App，得到本地 `.app`。
4. 试用包未公证。若 Gatekeeper 拦住，右键打开。可看 `scripts/clear-app-quarantine.sh`。
5. 把自备的混源 Log 文件夹拖进窗口（或点「添加…」）。仓库不带厂商样片。左侧应先出现「正在读入…」，然后写「读入 N 条」和下一步。空文件夹或没有 MOV / MP4 / TIFF / DPX / EXR 时应写「没有能读的素材」，列表不凭空多一条。若先筛了「已锁定」再拖入待选，筛选应回到「全部」，新条目能点到。每一行在成对 IDT 下面应有画面信息：影片是宽高、帧率和时长里读到的那些；静帧写「静帧」。读不到的不出现，也不要出现凭空的 24 或 30。点一条后，监视器和检查器标题下应是同一行。左侧这一行和检查器标题旁应有一张小图，角上写「源」，是源的第一帧，不是监视器里的调色画面。拖滑条时这张小图不换帧。解不出来应写「没有画面」，不要自己选成对 IDT。
6. 在右侧为每条待选素材选成对 Log 与色域。成对 IDT 是一列，点一行锁定，选完仍停在这一条。只有两对时（例如 S-Log3 的两个色域）应直接看见那两行，没有查找框。整表较长时，在「查找 Log 或色域」输入索尼或 Sony，列表应收窄；只剩一行时也不会自己锁定。点「清空」或换一条，查找应空掉。没有匹配时应写「没有匹配的成对 IDT」。监视器应出现源和预览，角标为「仅预览」。
7. 拖曝光或白平衡，预览应跟着变。监视器标题下那一行读数应一起变，有色温时带上绿品。也可点 −0.10、归零、+0.10，或色温的 −100 K、+100 K、回到机内，或绿品的 −1、绿品归零、+1，或用菜单「调色」。绿品归零只把绿品收到 0，色温不动。没有机内读数时，回到机内会清空色温，不猜 5600，绿品也不能步进。改完曝光或白平衡后，点「撤销这一套」或按 ⌘Z，数字应回到上一次；再点「重做这一套」或按 ⇧⌘Z 回到刚才。一次拖动滑条只退回拖之前。成对 IDT 和预览帧不因撤销改变。在「查找 Log 或色域」里按 ⌘Z，应改文字，不改这一套。写出进行中这两下是灰的。点另一条素材，曝光和白平衡的数字应留在原处；回到机内才换成当前这条的机内读数。影片有帧范围时，点「上一帧」「下一帧」或按左右方向键，预览帧应跟着走，读数里的曝光和白平衡不改。到头就停。读到帧率时，滑条下面这一行应有预览时间，写成当前 / 最后一帧（这一帧除以这条帧率，到毫秒）；读不到帧率就不要出现凭空的时间。点「回到开头」或按 Home 应回到第 1 帧并停住播放；点「到结尾」或按 End 应到最后一帧。已经在开头或结尾时，对应按钮是灰的。静帧没有这两下。读到帧率时，应能点「退 1 秒」「进 1 秒」，或按 ⇧←、⇧→，一次大约 1 秒，到头就停。读不到帧率就不要出现这两下。点「播放」或按空格，帧数应按这条自己的帧率往前走，读数旁出现「播放中」；这一帧还没画完时帧数应停住，不应跳到后面。到最后一帧就停，不绕回。再按空格是暂停。拖滑条、换一条、点灰卡、打开设置或写出说明，播放应停。静帧或读不到帧率时没有「播放」。已锁定后点「看调色前」（或 ⌥⌘\）：预览画面应去掉曝光和白平衡，检查器数字留在原处，读数仍写出这一套。再点「回到调色」，画面回到这一套，帧数不改。未锁定时这项是灰的。这仍是预览，不是最终画面。点「100%」或「200%」，画面应放大并停在中央，拖动可看旁边，分屏时左右一起动；再点「适应」回到整幅并回到中央。这是预览像素，不是片源逐像素。点灰卡时画面应回到适应，点完回到刚才的放大和拖到的位置。放大不改检查器数字，也不改写出。把窗口拉矮：检查器标题留在上面，下面能滚到曝光和白平衡。展开「高级」后，中间仍留着预览，里面可看直方图和亮度波形。波形不参与写出。监视器上「这次预览」可在 Rec.709 / HLG / PQ 之间换，不改设置里的默认，也不改写出。左侧可筛「待选」或「已锁定」，监视器不跟着筛选自己换条。
8. 点「处理已锁定片段」或顶栏「写出」（没有已锁定时这项是灰的）。说明面板列出每条会写出的源文件名和成对 IDT、将得到的代理名，以及每条会跳过的文件名和原因，并写明当前这一套曝光和白平衡。读到画面信息的条目，说明里跟左侧是同一行。默认代理名是 `{名}_Rec709_proxy.mov`。说明里的占用估算应是 ProRes（按每像素 1 字节），不是 EXR 的未压缩浮点图。说明里写明：确认后选文件夹贴在这个窗口上，取消则不写出。确认并收起后，顶栏应写「正在打开选文件夹」，写出条写明选文件夹会贴在这个窗口上。选文件夹应贴在主窗口上，占用和说明面板同一套。点取消则不写出，顶栏回到可调色再写出。磁盘明显不够时，应停在「磁盘空间不足，未写出」，文件夹里没有刚写出的代理。
9. 默认得到 `{文件名}_Rec709_proxy.mov`。整段代理，代理精度。写出时，监视器下应写「写出代理 i/N · 这条文件名」；读到总帧数再写「第 k / 共 m 帧」，静帧是共 1 帧。读不到帧率或时长时不要出现凭空的 24 或 30。左侧正在写的那一行应标「正在写出」。写出完成后，顶栏应写「已写出代理。可再调色，或在状态栏打开 Finder」。这一行在「已写出代理」下应有刚得到的文件名；点「已写出代理」应在 Finder 打开这个 `.mov`。状态栏仍可点「在 Finder 中显示」。失败的那一行不要打开 Finder。
10. ⌘, 打开设置：改默认预览或外观，应立刻生效，没有保存按钮。「未锁 IDT 挡住处理」保持不能关。
11. 展开「高级」可改写出格式、看节点，并在有预览时看直方图和亮度波形。两者都不参与写出，也不是示波器读数。

CI 绿不等于达芬奇已验证。没有 Mac、没有达芬奇、或没有自备片子时，真机验收记「未跑」。
