# LogBridge 界面计划

本文件记产品边界、信息架构和本机验证步骤。色彩数字仍以 `color/` 与现有测试为准。整段代理，代理精度。已实现（未验证）。

## 产品定位

LogBridge 是 macOS 上的本地调色与交付工具：混源 Log 素材选出成对 IDT，看预览，写出剪辑软件能打开的代理（默认 ProRes 422 HQ；高级可选 ACES2065-1 EXR），并可带达芬奇节点包。

它不是剪辑软件。不剪多轨，不提供模板或特效货架。

## 现有栈与主路径

- 界面：SwiftUI，单窗口，macOS 14+。工程在 `macos/LogBridge/LogBridge.xcodeproj`。
- 色彩真源：`color/`（Python）。App 里的预览和写出走同一套已有公式，本轮不改数字。
- 文案：`locale/ui_zh.json` 与 `UICopy.swift`。

主路径：打开 → 拖入或「添加…」→ 每条选成对 IDT → 预览里看曝光和白平衡 → 「处理已锁定片段」→ 写出说明 → 选文件夹。

未锁定的素材跳过，不猜 IDT。

## 仓内核实

- **没有剪辑时间线。** 预览下方只有帧滑条（有帧率元数据才出现）。仓库里的「时间线」字样出现在达芬奇包说明，指 ACEScct 工作空间，不是多轨时间线。本轮不加重轨。
- **示波器不进默认界面。** 友好版只在「高级」里放直方图，标明仅预览、不参与写出、不是示波器读数。波形和矢量以后再评估，仍默认收起。

## 信息架构

对照四家之后采用的做法：

- 单窗三区：素材列表 | 大预览（角标「仅预览」）| 右侧检查器（跟当前选中）。
- ⌘, 是全局偏好：默认预览、默认写出格式、外观、导入后是否提示估计白平衡。改完即生效，没有保存或取消。
- 本片：成对 IDT 记在当前素材上。曝光和白平衡改完即在预览里生效；写出时，已锁定素材共用检查器里当前这一套曝光和白平衡，每条仍用自己的成对 IDT。
- 写出是独立说明面板，确认后再走原来的选文件夹。不放进偏好设置。面板列出每条会写出的文件名和成对 IDT，以及每条会跳过的文件名和原因。
- 节点、EXR、直方图在「高级」，默认收起。

不采用的做法：多页工作区、自由拆窗、把节点图当成第一眼、用宣传口径把代理说成已经做完的画面。

## 本轮界面

- 顶栏：添加、设置、写出。
- 左侧素材列表加大拖放区和行高。点一行只选中并刷新预览。
- 中间监视器尽量占高。默认左源右预览。可切到「预览」把调色画面放大；点灰卡时仍显示预览。空窗口写明拖入或点添加。
- 右侧检查器：成对 IDT，再是可折叠的曝光和白平衡（默认展开）。标题固定，下面整栏滚动。窗口变矮时仍能滚到曝光和白平衡。
- 曝光打开时，滑条旁有 −0.10、归零、+0.10。和监视器读数是同一套，预览跟着变。范围仍是 −8 到 +8 档。写出仍用当前这一套。写出进行中或设置、写出说明打开时，步进不起作用。
- 白平衡打开且已有色温时，滑条旁有 −100 K、回到机内、+100 K。每次 100 K，范围仍是 2000 到 10000。回到机内恢复这条的机内色温和绿品；读不到机内就清空，不猜 5600 或 6504。色温空着时不能步进。写出进行中或设置、写出说明打开时，步进和回到机内不起作用。
- 监视器标题下有一行读数：当前素材名、曝光档、白平衡。和检查器同一套数字，仅预览，不参与写出。
- 预览至少留一块高度。写出条收成少量行，把高度留给预览。主按钮先打开写出说明。说明面板收起后才打开系统选文件夹，避免两层叠在一起。写出进行中同一按钮变为「取消」。
- 「高级」展开后在自己的高度里滚动，不把监视器顶没。直方图下面有亮度波形，按当前预览从左到右铺开。仅预览，不参与写出，不是示波器读数。默认收起。
- 菜单「调色」：曝光 +0.10（⌥⌘=）、曝光 −0.10（⌥⌘-）、曝光归零（⌥⌘0）、色温 +100（⌥⌘]）、色温 −100（⌥⌘[）、回到机内（⌥⌘9）、下一条待选（⌘]）。和检查器是同一套，不另记数字。
- 素材已进来但当前这条还没锁定时，监视器底部和写出条都会写下一步：到右侧检查器选成对 IDT。选完才出现「处理已锁定片段」。
- 选完成对 IDT 后仍停在这一条，预览按这一对重算。还有别的待选时，检查器有「下一条待选」，不替你选。
- 写出说明在收起之前一直是写出说明，不会中途换成设置。说明里写明当前这一套曝光和白平衡，这一套会套到已锁定素材。每条仍用自己的成对 IDT。
- 全局偏好增加外观（跟随系统 / 深色 / 浅色），只改窗口明暗，不改预览色彩标签，也不改写出。

## 在 Mac 上试用

Linux 上不能编出 `.app`。下面交给本机 Xcode。

1. 安装 Xcode 15 或更新。
2. 打开 `macos/LogBridge/LogBridge.xcodeproj`。
3. Scheme 选 **LogBridge**，运行（▶）。或 Product → Archive → Distribute App → Copy App，得到本地 `.app`。
4. 试用包未公证。若 Gatekeeper 拦住，右键打开。可看 `scripts/clear-app-quarantine.sh`。
5. 把自备的混源 Log 文件夹拖进窗口（或点「添加…」）。仓库不带厂商样片。
6. 在右侧为每条待选素材选成对 Log 与色域。监视器应出现源和预览，角标为「仅预览」。
7. 拖曝光或白平衡，预览应跟着变。监视器标题下那一行读数应一起变。也可点 −0.10、归零、+0.10，或色温的 −100 K、+100 K、回到机内，或用菜单「调色」。没有机内读数时，回到机内会清空色温，不猜 5600。这仍是预览，不是最终画面。把窗口拉矮：检查器标题留在上面，下面能滚到曝光和白平衡。展开「高级」后，中间仍留着预览，里面可看直方图和亮度波形。波形不参与写出。
8. 点「处理已锁定片段」或顶栏「写出」。说明面板列出每条会写出的文件名和成对 IDT，以及每条会跳过的文件名和原因，并写明当前这一套曝光和白平衡。确认并收起后，再出现选文件夹。若文件夹窗口没出来，再点一次「处理已锁定片段」，确认说明后继续等。
9. 默认得到 `{文件名}_Rec709_proxy.mov`。整段代理，代理精度。
10. ⌘, 打开设置：改默认预览或外观，应立刻生效，没有保存按钮。「未锁 IDT 挡住处理」保持不能关。
11. 展开「高级」可改写出格式、看节点，并在有预览时看直方图和亮度波形。两者都不参与写出，也不是示波器读数。

CI 绿不等于达芬奇已验证。没有 Mac、没有达芬奇、或没有自备片子时，真机验收记「未跑」。

## 下一轮优先

1. 在 Mac 上走完上面 5–10 步。本轮已让检查器整栏可滚，监视器显示当前曝光和白平衡，高级展开不再顶掉预览。仍要看写出说明会不会挡住选文件夹。
2. 若要「每条素材各自记住曝光，并按该条写出」，那是写出行为变更，需单独改并补测试。本轮保持现在的共用一套曝光和白平衡。
3. 亮度波形已在「高级」，跟直方图一样只看当前预览。默认界面仍不放示波器。色温步进和回到机内已在检查器，写出说明会写出当前这一套曝光和白平衡。
